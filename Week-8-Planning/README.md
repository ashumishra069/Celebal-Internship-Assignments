# E-Commerce Analytics System

## Overview

This project is an end-to-end e-commerce analytics system built using Python, Pandas, SQLite, and SQL.
The project covers data generation, data cleaning, data validation, database analysis, customer retention, customer segmentation, and reporting.

## Technologies Used

- Python
- Pandas
- SQLite
- SQL
- Faker

## Project Features

- Generate synthetic e-commerce data
- Clean and validate CSV data
- Handle missing values and duplicates
- Handle invalid dates and IDs
- Check referential integrity
- Store data in SQLite
- Perform SQL JOINs and aggregations
- Use CTEs and window functions
- Perform cohort and retention analysis
- Perform customer segmentation and RFM-style analysis
- Generate reports using a CLI tool

## Dataset

The project uses four datasets:

- Customers
- Products
- Orders
- Order Items

The raw datasets are stored in `data/raw/` and the cleaned datasets are stored in `data/cleaned/`.

## SQL Analysis

The project includes analysis for:

- Customer revenue
- Revenue by category
- Monthly revenue
- Top products
- Customer lifetime value
- Running totals
- Moving averages
- Revenue growth
- Cohort analysis
- Customer retention
- Customer segmentation

## CLI Reports

The reporting tool supports three reports:

- `revenue`
- `top_customers`
- `retention`
