# Week 3 SQL Assignment

## Objective
Analyze the Superstore dataset using Subqueries, CTEs, Window Functions, and JOINs to solve business-related queries.

## Tasks Performed
- Imported the Superstore dataset
- Created customers, orders, and products tables
- Inserted data using select distinct
- Solved SQL queries using:
  - Subqueries
  - CTEs
  - Window Functions (`rank()`, `row_number()`)
  - JOINs
- Answered mini project questions such as top/bottom customers, above-average sales, and highest order value.

## Tools Used
- MySQL Workbench
- MySQL

## Outcome
Gained experience with advanced SQL concepts for data analysis and customer sales insights.
